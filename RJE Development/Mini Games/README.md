# Mini Games

| Folder | Contents |
|---|---|
| [Casino](Casino/) | Casino menu, wallet, blackjack tables and spectator controls |
| [Bets](Bets/) | Poker wagers, pots, payouts and match betting |
| [Poker and arena](Poker%20and%20arena/) | Poker hands, table UI, arena challenges and shared blackjack functions |
| [Development history](Development%20history/) | Casino and observer-poker prototypes, artwork tools, rule tests and verification records |

The scripts are archived extracts for 799X, Solo Foots and FFA Foots. Their shared declarations are in [Integration](../UI%20Development%20Work/Integration/). The [profile scripts](../UI%20Development%20Work/Profiles/) include the casino statistics.

The [casino and poker artwork](https://github.com/NorthStarEnergy/Footmen-Frenzy/tree/2a1141817975c151b6e9bb214071f98e33c998d6/RJE%20Development/Mini%20Games/Casino/Assets) includes both UI sets and the font license. The [retired standalone project](https://github.com/NorthStarEnergy/Footmen-Frenzy/tree/2a1141817975c151b6e9bb214071f98e33c998d6/projects/casino) provides the original map context.
